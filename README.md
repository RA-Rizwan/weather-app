# Weather App

A minimalistic weather application that provides accurate weather information for any city using the OpenWeatherMap API.

## Features

- Clean and modern UI
- Real-time weather data
- Temperature in Celsius
- Humidity and wind speed information
- Weather description
- Responsive design

## Setup

1. Get an API key from [OpenWeatherMap](https://openweathermap.org/api)
2. Open `script.js` and replace `'YOUR_API_KEY'` with your actual API key
3. Open `index.html` in your web browser

## Usage

1. Enter a city name in the search box
2. Press Enter or click the Search button
3. View the current weather information for the selected city

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeatherMap API
